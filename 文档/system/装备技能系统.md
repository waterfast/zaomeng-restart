# 装备技能系统

## 目标与范围

装备通过显式资源引用授予角色触发技能。首个效果为如意金箍棒：每次造成伤害大于零的暴击，恢复最大生命和最大魔法的各 20%，不超过当前上限。普通攻击和技能的有效暴击都可触发，每次命中分别结算；闪避、无伤害、友方、尸体和无敌目标不触发。该数值用于验证功能，可直接在游戏数据中调整。

本次实现即时触发效果，不实现装备主动技能槽、持续 Buff、套装、概率触发、触发冷却或效果等级。角色已学技能和装备授予技能分别归属学习系统与装备系统，装备技能不写入学习记录。

## 模块与数据归属

- `EquipmentDefinition.GrantedSkills`：只引用装备授予的技能，不存放效果名称、正文、触发参数或战斗分支。
- `EquipmentSkillDefinition`：GameData 中的技能 ID、英文名称键、说明模板键及独立效果资源。名称和正文由翻译表提供。
- `EquipmentSkillEffect`：即时触发效果接口；`CriticalResourceRecoveryEffect` 配置恢复比例并消费已结算命中。资源只保存配置，不保存玩家状态；效果行为不认识装备 ID。
- `EquipmentSkillRuntime`：玩家拥有的当前授予技能快照，根据实际穿戴装备重新建立，统一派发命中。相同技能 ID 去重，不因多次刷新或多个装备重复叠加；相同 ID 对应不同定义报错。
- `Player`：拥有血蓝、汇总属性和装备技能运行集合；属性刷新完成时同步技能集合，战斗命中时将已结算结果交给集合。
- `CombatResolver`：负责命中、闪避、防御、暴击及伤害结算。只有目标接收有效伤害后才派发装备技能触发，不让效果自行重算暴击。
- `ItemDescriptionBinding` + `EquipmentSkillListView`：背包共用正文和技能图文展示组件，读取物品正文键及装备技能引用，用同一效果参数格式化描述。`ItemDescriptionBuilder` 供纯文本消费者使用。未穿戴装备也可预览授予技能，已穿戴装备显示相同定义。
- `Content/Localization/game_data.csv`：物品正文、装备技能名称、说明模板及说明标题的中英文文本；游戏数据保存稳定英文键，不在装备资源或背包代码硬写效果正文。

## 依赖与调用链

装备请求 → `EquipmentService` 提交穿戴及背包交换 → 背包变更通知 → `GameplayEquipmentBinding` 调用玩家刷新 → 汇总属性 + 重建装备技能集合 → UI 通知与保存。

角色首次绑定/加载同样走玩家刷新；丢弃、出售已穿戴装备等成功操作通过原变更链同步。刷新不治疗、不启动效果、不添加事件订阅。卸下后下一次命中不再触发；角色切换时覆盖旧集合。派生集合不写存档，只存装备实例引用。

有效命中 → `CombatResolver` 创建 `HitResult` 并让目标受伤 → 玩家装备技能集合 → 效果判断已结算的暴击及正伤害 → `Heal`/`RestoreMana`。

背包悬停/详情 → `ItemDescriptionBinding` + `EquipmentSkillListView` → 翻译物品正文 → 读取 `GrantedSkills` → 翻译技能名称、按参数格式化说明。界面不通过物品 ID 推断效果，也不复制效果数值。每次刷新重新取翻译；已经打开的悬停说明接收语言变更后刷新。

## 注册与扩展

在 `Content/GameData/EquipmentSkills` 创建技能及效果资源，补齐翻译键，然后显式加入某件装备的 `GrantedSkills`。物品目录通过引用关系递归验证技能；不另建重复目录。新触发效果添加独立效果子类及资源，不修改玩家中的装备/技能 ID 分支。

物品正文统一使用 `DescriptionKey` 引用文本表。当前其他物品名称沿用既有显示字段，不把本次范围扩大为整个 UI 或已学技能的国际化重构。英文键是内容标识，国际化支持与旧系统/存档兼容无关。

## 失败处理与验证

目录拒绝空技能、重复授予 ID、同 ID 不同定义、缺失效果/翻译键、非有限比例及超出 0～1 的恢复比例。重建先生成完整新集合，再替换旧集合，验证失败不保留半个新集合。

独立测试场景不访问存档：真实装备/卸下请求与刷新链；确定性暴击和非暴击；闪避、零伤害、无敌及致死命中；血蓝恢复上限；多个来源去重与重复刷新；切换角色移除旧效果；中文和英文说明与效果参数一致；两种背包说明组件共用技能列表组件；纯文本消费者可使用 ItemDescriptionBuilder。构建后运行测试及相关装备回归。

## 图标与等级

装备技能定义自身拥有图标、翻译键和 MaximumLevel（默认1）。装备仅引用 GrantedSkills 数组；说明组件读取各技能的翻译和效果参数，显示图标与等级。没有图标时用纯黑框。多技能逐项展示和同步，不把效果描述拷贝进装备数据。
