# 地图陷阱系统

地图场景显式放置地刺节点，地形由分段 RectangleShape2D 配置；图像、可站立面与伤害区域分别管理。TrapDefinition 保存伤害、预警/伸出/收回周期，GroundSpikeTrap 管理计时、动画与本次伸出命中集合；场景保存原图引用及36×48矩形伤害区域。预警不伤害，每次伸出对玩家最多命中一次；无敌、死亡和暂停遵循角色/场景生命周期。伤害使用真实伤害 HitResult，不伪造怪物或污染掉落。旧版地刺50真实伤害、位置依据关卡脚本；摆放脚点以当前地图地面射线核对，旧位置400为出生并非最终站立高度。

扩展陷阱通过独立节点/资源实现，关卡只装配地图。验证周期边界、停留与重入不重复命中、无敌、地面脚点、矩形碰撞及六关实际移动/门禁/出口。落石、七星洞机关、船舶与水域机制需单独核对实现，不能用地刺完成宣称覆盖所有机关。
