# 音频系统

目标：恢复旧工程实际音乐与音效，统一管理全游戏播放，设置可以更换背景曲并立即生效。

## 职责与状态
AudioManager 为常驻 Autoload，拥有一个音乐播放器和有上限的音效播放器池。MusicTrack / AudioCatalog 显式注册曲目、菜单默认曲、拾取、界面点击、胜负音效。场景入口选择菜单或关卡音乐；关卡默认曲由 LevelDefinition 引用。角色受击、死亡与命中声音由 ActorSoundProfile 引用；普通攻击和技能资源各自引用出招声音；法宝独立施放也消费其 Action.Sound，火魔斩的空中与落地声音在独立行为组件按动作阶段触发，弹体行为可配置释放声音，通用代码不判断角色或技能 ID。

GameSettings 拥有本机的音乐、音效、拾取音效开关、两路音量以及菜单和关卡曲目偏好。空曲目 ID 表示跟随场景默认；未知 ID 回退默认。背包拾取成功才播放音效，闪避不播放命中声，已接受的出招才播放挥击声。死亡声音代替当次受击声音。

## 调用链与扩展
主菜单、世界地图 → AudioManager.EnterMenu；GameplayLevel → EnterLevel(配置曲目)，结算 → PlayResult。Settings.Changed 通知管理器刷新，相同音乐不重新开始。音乐循环、持续跨场景；关卡暂停时战斗音效暂停，背景音乐与设置点击继续播放。退出关卡清理残余战斗音效。

新增曲目在 Content/Audio/Registry.tres 登记；新增动作通过 AttackStep / SkillDefinition 的 Sound 引用；新角色通过 SoundProfile 引用。音频从旧工程 .import 的真实缓存路径恢复，Assets/Audio 保留来源目录，不从网络合集抽取未知音轨。

## 失败处理与验证
未配置声音跳过播放，不阻断玩法。音效池最大 24 路，同声音 40ms 内合并以避免群体伤害爆音；超出池时轮换复用声道。设置保存失败由原有 UI 提示。验证资源可解码、曲目默认与选择、同曲不重启、保存重载、静音与暂停、声道数量及实际场景动作接入。

## 迁移来源
旧 MainMusic.gd 与 main_set.gd 默认 music=1，菜单和地图使用造梦1主题；旧 Level_1.gd 至 Level_3.gd 使用 1_music。117 个 MP3 从对应 .import 指向的 mp3str 恢复原始数据；造梦2 OGG 保留为 AudioStreamOggVorbis 资源。出招按旧角色动画调用的声音编号和技能函数核对。尚未实现的角色声音只保留在素材目录，不声明已经接入。B 站[历代音乐收录](https://www.bilibili.com/video/BV1zq4y1y7BW/)和[造梦1音乐大全](https://www.bilibili.com/video/BV13W411T7ND/)作为曲目资料参考，本次实际资源来自旧工程缓存。

## 本次验证结果
118 份恢复音频可加载并创建播放实例；24 首登记曲目可选。AudioSmokeTest 验证场景默认、实时选曲、重载配置、同曲不重启、静音、拾取音效独立开关、真实挥击/命中/受击/死亡、密集音效有限声道，以及局内完整设置关闭后保持暂停。GameSettingsSmokeTest 与 LevelModesSmokeTest 回归通过。设置界面已渲染检查。尚未实现的角色/动作声音未绑定，添加内容时需在对应资源显式引用。
