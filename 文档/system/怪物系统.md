# 怪物系统

## 目标与范围

怪物和玩家共用 CharacterActor、SkillDefinition、SkillCast、SkillBehavior 和伤害结算。怪物身份不能决定通用脚本中的技能分支。先迁入花果山小猴、妖猴、大猩猩（普通与 Boss 两个配置）；人间其余关卡先迁地图，不能用花果山怪物冒充其原版怪物。

## 模块、数据与运行状态

- MonsterDefinition：显式引用表现场景、基础属性、AI 视距、奖励、技能列表和掉落表。同一表现场景可以登记不同属性、技能与掉落的模板，例如普通大猩猩和 Boss 大猩猩。
- MonsterSkillChoice：引用共享 SkillDefinition，配置施放等级、距离、生命区间和优先顺序。技能动作动画必须由使用者场景提供；共享技能并不意味着自动生成缺失动画。
- Monster：只负责读取目标、选技能及追击；模板不存冷却、生命或目标。每只怪独立持有技能冷却。
- MonsterPool：以模板资源为键复用节点，关卡波次直接引用模板，移除固定整数到场景的映射。每次出生从模板重新计算属性，叠加本次难度倍率，不能累计乘算。
- MonsterDropTable / MonsterDropEntry：支持总掉率、按权重抽一项或逐条独立判定，以及各条数量范围，允许同一怪掉多种物品；奖励归关卡库存服务处理，UI 预览与实际掉落读取同一表。
- CharacterActor：共用特殊行为生命周期；打断、死亡、回收和退出立即清理。SkillBehavior 接受 CharacterActor；弹体和范围技能通过阵营选敌，不限定 Monster 或 Player。

调用链：关卡定义 → 波次模板引用 → 对象池配置与重置 → 怪物 AI → CharacterActor.TryUseSkill → SkillCast + SkillBehavior → CombatResolver。死亡 → 遭遇事件（仅一次）→ 模板及模式掉落判定 → 场景 ItemPickup → 玩家走近拾取 → 库存与保存。地面掉落职责见物品系统设计。

## 难度、再战与扩展

关卡模式分别提供小怪/Boss的生命、攻击、防御倍率与等级覆盖，并独立增加两类额外掉落；单怪变化用新的模板引用同一表现场景，并覆盖基础属性、技能与掉落。再战作为独立关卡变体引用新模板，不在怪物脚本判断关卡名、困难或再战次数。不保留旧接口兼容层。

普攻/多段/冲刺使用动作和命中资源；弹体、治疗、落地范围攻击由独立共享行为实现。召唤、持续地面危险、状态效果、变身和复杂 Boss 阶段需要各自独立行为/阶段组件，尚未实现，不能宣称已经支持系列全部技能。扩展时保持此接口并给行为添加配置校验和中断验证。

## 失败处理与验证

入关前拒绝空模板、重复 ID、缺失场景、非法倍率、掉落 ID 未注册和无效波次；技能无动画时拒绝施放，不扣费、不启动冷却。池回收清除行为及命中框。测试隔离到槽位 0，覆盖不同模板、困难与复用不累计、独立掉落、怪物施法与玩家施放同一技能、打断清理，以及人间地图真实移动巡检。

## Boss 动画巡检与修复设计

- 猕猴王风弹的手上蓝球由动作轨道控制，从第 0 帧出现并随三种手势移动；受击、死亡和待机清除。旧场景在 0.7、1.4 秒各释放一次，弹体由共享 `ProjectileSkillBehavior` 的有序 `ReleaseTimes` 驱动，从显式 `OriginPath` 指向的手上节点世界位置生成；未配置锚点的技能使用 `SpawnOffset`。每次施法独立记录已释放数量，打断取消后续释放，已飞出的弹体继续独立运行。手上蓄力是本轮补充表现，旧场景没有独立的蓄力节点。验证逐帧起手可见、两次弹体命中、左右手部衔接和中断清理。

- 独立 `Tests/BossAnimationShowcase.tscn` 显式引用 Boss 模板，按技能列表依次施放，覆盖当前登记的大猩猩、猕猴王、禺狨王；尚未迁入的后续 Boss 不在范围内。关闭 AI 与玩家输入，保留真实物理、动画时钟、命中和技能行为，不读写存档。左右各播放一轮，可暂停、切换动作、重播和调速。
- 身体和随身光效归表现场景的动画轨道管理；待机、受击、死亡立即复位光效，避免中断及池复用残留。猕猴王震击复用通用多段命中窗口，恢复旧场景的帧序列、阶段缩放、碰撞形状和 1.5 倍节奏；同步换算动画时间和命中窗口，移除单次范围攻击替代实现。
- 当前角色以根节点为脚点；猕猴王身体与震击两阶段的垂直偏移按原图非透明底边校准，避免直接沿用旧坐标原点造成离地。新 Boss 的普攻从模板技能列表施放，清除继承自小猴场景的无关普攻配置。
- 禺狨王补回旧场景 `SpecialEffect` 的普攻/施法光效，目标爆发仍由共享范围行为实现。世界脚点在添加节点后设置，视觉锚点显式配置，避免按首帧高度猜测造成悬空。
- 范围行为只负责锁定、预警与延迟释放；释放后的 `AreaAttackEffect` 独立持有播放时钟和命中窗口。每窗口每敌人一次，允许窗口内走入后命中，原爆发六段窗口从特效第 10 帧开始；施法者死亡、隐藏或出生修订号变化后清理。技能动作结束不提前截断已经释放的爆发；未释放时受击会取消。此组件只支持有确定时长的范围爆发，不宣称支持持续地面危险系统。
- `--verify` 完整播放后退出，检查动作开始、实际命中、结束、光效清理及左右镜像，附加震击多段、中断和池复用检查。可见窗口下 `--capture-boss` 保存关键帧至 `.godot/boss-checks`；headless 不能替代视觉检查。

## 迁移边界

旧工程来自同级 `造梦八荒-(4.1)`，美术补充来自 `zmbh-rebuild/assets`。旧逻辑中的按场景名变更属性拆成模板。旧版特殊条件天庭令牌奖励不在本轮范围；不得自动登记不存在的物品。数值和掉落迁移差异记录在关卡迁移清单中。

## 本轮已实现与数值边界

`Content/Monsters/Templates` 登记小猴、妖猴、普通大猩猩、Boss 大猩猩以及两个魔化变体。旧怪基础生命/攻击/防御/等级/经验/灵魂已核对；小猴0.22、妖猴与普通猩猩0.18掉率及其旧普通装备列表已迁入，每次至多一件。Boss保留当前试玩工程的三件必掉装备，这不是原版无条件掉落（旧版普通掉落列表为空，仅有天庭令牌特殊条件）；困难现改为20级试玩强度（详见关卡选择与配置系统）；动作冷却、视距与速度换算仍为试玩配置，不宣称旧版精确平衡。

模板不仅可改变生命和攻击，也可配置防御、暴击/抗暴、闪避/命中、韧性、穿透、吸血、幸运、移动与技能列表。当前一图模板只迁常规近身动作；妖猴旧随机攻击意愿与行进中出招节奏没有完整还原。尚无再战关卡策划资源，但可用同一场景的新模板组合再战变体。

已通过 MonsterTemplatesSmokeTest：共享治疗分别作用于玩家与怪物、怪物共享弹体命中玩家、受击中断不补发治疗、缺失动画提前拒绝、独立掉落与池复用倍率。原技能目录、花果山4波＋Boss和结算回归通过。

怪物冷却支持行为通知后延迟启动，与玩家同一通知接口；池复用通过出生修订号隔离旧弹体/跟踪效果，避免同一节点的新出生继承旧技能。延迟冷却与复用弹体清理已加入专项验证。

## 条件式固有被动

MonsterDefinition.PassiveSkills 显式授予公共 PassiveSkillDefinition；Apply 与池复用重建固有来源，不使用怪物 ID 分支。猕猴王引用通风大圣，当前血量严格低于 20% 时伤害 ×2、动作攻速 ×1.5、攻击范围与特效大小 ×1.5。AI 选择距离同步采用范围倍率；不修改模板基础属性。回血退出条件，永久 Boss 阶段另行设计。BossAnimationShowcase 支持“普通 / 低血量”切换与 --rage-boss 巡检，后者按已登记血量条件设置低血量。

## 后六关扩展设计（实现中）
飞行怪使用独立 FlyingMonster 场景脚本，技能行为资源显式接入弹体与召唤，不在 Monster 中判断怪物编号。召唤接口由 WaveEncounter 注入，召唤物计入当前遭遇存活数并由同一池回收；召唤物关闭物品和经验奖励，避免重复刷资源。特殊机制作为 MonsterMechanic 子节点附在首领场景，重生/回收同步清理。蝙蝠石像的护盾通过通用 Buff 承担减伤，弱点触碰打开五秒伤害窗口。旧方法轨道仅用于提取释放时机，不执行旧函数。
# 六关首领与状态扩展

怪物技能选择可声明运行模式，由独立 FlightPhaseMechanic 控制地面/飞行时段、重力和空中动画，通用 AI 只匹配模式。鹏魔王地面喷火与空中喷火分资源，喷火行为可配置三向弹体；飞行冲撞用原 FlyBirds 动画与 TargetChargeBehavior 锁定位置俯冲，通过身体碰撞移动；低血量化卵优先于飞行。HealthPhaseMechanic 可在低血量首次触发资源引用的召唤，WaveEncounter 统一计入活怪数量。召唤物无奖励，主人死亡时一并清理，防止刷奖励和通关后残留。

命中资源引用 BuffDefinition 接入中毒、灼烧、流血、减速和眩晕；定时伤害保留来源与出生版本，来源回收后不会归属到复用后的怪物。迁移不调用旧方法轨道。

## 龙王地面序列扩展

两套龙王显式登记于Content/Monsters/DragonKing，共用DragonKing演员；入口按资源配置的21级门槛选择目的地。GroundAttackSequenceBehavior启动独立有限序列，按时机和偏移生成AreaAttackEffect；高阶冰雪起招锁定脚点，水龙释放时采样目标。受击取消未生成的延迟冰雪，死亡、隐藏和出生修订变化取消全部后续序列及爆发。VisualMaterial保留旧水龙叠加材质，AlignVisualToGround固定寒冰底边；命中窗口、阵营和状态使用共享组件。高速弹体改用运动线段检测命中矩形，防止跨帧穿透。BossAnimationShowcase现显式登记低高阶龙王，按序列寿命等待世界效果清理。具体掉落范围和验证见[水晶宫隐藏关卡](水晶宫隐藏关卡.md)。
