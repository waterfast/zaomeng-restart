# Buff 系统

## 目标与范围
角色、装备与消耗品共用资源驱动的增益状态。支持定时刷新、来源移除、治疗脉冲、范围伤害、伤害倍率、极速与经验/灵魂奖励加成。地煞之灵随装备存在；烈焰风暴使用施法绑定的多次范围伤害。节日食品可引用相同 BuffDefinition，不在运行时判断物品或角色 ID。节日食品本轮只提供接入口，未确定的策划资源不冒充已迁入。

## 模块职责与状态
BuffDefinition 保存不可变配置（ID、名称、图标、持续时间、数值、脉冲命中），BuffRuntime 属于每个 CharacterActor，保存来源、剩余时间、脉冲时钟与奖励小数余量。相同 ID 不累计数值，同来源重施刷新时长；不同来源保留各自时长，移除其中一个不清除其他来源。聚合按 ID 去重，取等级最高的一份。装备被动定义通过 BuffGrantEffect 声明授予，由装备来源同步重建。被动系统继续管理攻击条件，不承担定时器。

## 调用链与扩展
技能行为在释放帧 Apply，施法绑定状态在停止时 RemoveSource；装备刷新同步持续来源；食品通过运行中的玩家入口 Apply。角色物理帧 Tick；战斗结算调用伤害倍率；击杀时经验及三颗灵魂总量分别按奖励倍率快照，灵魂到达时只入账，不再乘倍。小额增益的小数累积到后续击杀，防止每颗1灵魂乘1.2再截断导致增益失效。UI 使用旧 HUD 的 role_hp_mp_exp/Buff_box（角色框下方）展示活动图标；名称、说明与剩余时间放在悬停提示，不额外显示“装备”、倒计时等白字。关卡名和波次白字也已从 HUD 移除，GO 提示保留。

## 生命周期与失败
死亡清空临时状态及奖励余量，对象池重生清空全部并重建固有来源；换关不保留临时 Buff。无效/空配置拒绝应用，先验证再替换来源。资源无运行状态。重复刷新不会治疗或重置其他来源计时。装备奖励效果只能作用于怪物奖励，出售、任务、宝箱不受影响。

## 验证
检查持续时间与刷新、两来源去重和独立移除、装备穿脱、20%小额奖励累积、范围敌我判断与脉冲次数、死亡与池复用、食品无玩家时不消耗，以及已接入技能回归。

## 当前接入与约定
地煞灵戒原属性上新增10极速，装备被动通过资源授予永久地煞之灵（经验与灵魂各+20%）。烈焰风暴施法释放后0.31秒内四段脉冲，受击打断移除。大品天仙决已有独立装备被动定义 critical_resource_recovery，由如意金箍棒授予，有效暴击命中恢复最大生命、魔法各20%；不属于可学习主动技能，也不额外授予持续治疗 Buff。误登记的 dptxj 主动技能、成长、行为与治疗 Buff 资源已撤销。持续治疗能力用测试内存资源验证，不登记虚构策划内容。

同一系统也承载中毒、灼烧、流血、减速、眩晕和首领化卵状态：HitDefinition.AppliedBuff 在有效命中后施加，伤害脉冲保存来源演员与出生版本；移动乘数和禁行动由角色读取，范围伤害保存源技能以继续触发已有技能被动。伤害减免后的实际伤害才用于吸血和命中通知，完全挡伤时不会授予命中状态。食品配置 ConsumableEffect.ApplyBuff 与 Buff 引用即可接入；月老、福禄寿、月饼尚未指定数值，因此只有入口，没有伪造食品内容。

BuffAndSixLevelsSmokeTest 与 BuffTrapMechanicsSmokeTest 已通过穿脱、来源去重、奖励余量、到期最后一跳、食品消耗、真实四段伤害与受击打断验证。六关实际移动与原生渲染巡检通过。未实施跨关保留和 Buff 存档。

无双基本增益使用同一 BuffRuntime。FinalDamageMultiplier 在旧伤害公式后乘算，SuperArmor 免非致死受击打断与击退。BuffGrantEffect.OnlyDuringWushuang 通过现有被动来源在无双开启/结束及穿脱时同步；数值与注册示例见无双系统。伤害型持续脉冲显式零无双，范围攻击脉冲仍按源技能接触获取。
