# 法宝界面与主动系统

## 目标与范围

局内法宝详情是独立菜单，通过 B 或 HUD 法宝入口打开；背包法宝槽打开同一详情。菜单交由 MenuManager 管理暂停、互斥和 Escape。详情与帮助挂在 HUD，不能依赖背包可见性。关闭详情先关闭帮助。详情只读取穿戴实例，穿戴仍通过背包统一装备请求。

本批已接入地煞葫芦、天煞古剑、紫金葫芦的基础主动与旧帧图：三道火柱、七道落剑、近身火焰多段命中。已接入旧版无双获取：地煞葫芦、天煞古剑每接触+2，紫金葫芦15–20；未实现五行、成长、洗练、技能选择、灼烧、冰冻；详情说明实际范围，不显示已实现状态。

## 职责与数据归属

EquipmentDefinition 显式引用 MagicWeaponAbility；能力资源引用独立 SkillDefinition 和 BurstAttackDefinition，保存魔耗、冷却、释放点与命中窗口。MagicWeaponPresentation 只存展示数据。

MagicWeaponRuntime 是玩家子节点，读取角色当前法宝槽与物品目录，处理 H 输入、资格、扣蓝、冷却与释放，不按法宝 ID 分支。法宝独立于角色动作，可在普攻中使用；死亡、受击状态和无装备时拒绝使用。冷却按能力资源保存到运行态，更换法宝不清除冷却，避免切装重置。冷却不入存档。

BurstAttackDefinition 是共用范围爆发配置；BurstSkillBehavior 按角色动画时钟释放，MagicWeaponRuntime 按独立时钟释放法宝。两者调用相同的范围命中效果，不共享施法状态。释放后效果保留施法者出生版本，死亡、重置或退出时停止。未释放的法宝序列在换装时取消。

## 注册、失败处理与验证

物品目录显式登记法宝，怪物掉落表提供获得途径；角色技能在角色目录登记。能力与爆发配置由目录校验，拒绝缺失帧图、循环动画、无效命中窗口、负魔耗与无效时序。配置实例不进入存档。

验证独立入口、背包切换、空槽、帮助关闭、暂停恢复；穿戴、资源校验、H 扣蓝、冷却拒绝、换装不重置、伤害与阵营、死亡/重置清理；玄冰阵与九环圣经的学习、装配、施放、伤害及中断。

## 旧资源依据

地煞葫芦、天煞古剑、紫金葫芦分别核对旧 Global.gd 的法宝实例映射、AllEquipment.gd 与 Main_Backpack.gd 的物品图路径规则，以及 HitBullet.tscn 的 CucurFire_2、SwordBullet、PurpleGlodCucurbitBullet 帧图。物品图与技能图分开引用。旧 GDScript 仅用于核对数值与时序。

等级、成长率、五行与进度显示“—”，升级/洗练/设置禁用；空槽清空展示，无展示配置回退物品图。图标动画与帮助沿用旧场景。

## 本批实现与验证记录

天煞古剑加入猕猴王掉落候选，紫金葫芦加入禺狨王掉落候选，沿用50%掉落表触发与任选一件的规则；地煞葫芦沿用大猩猩掉落。唐僧两项技能从技能面板学习并装配，不自动赠送。

已通过零警告/零错误编译、MagicAndTangsengSmokeTest、ContentSystemsSmokeTest。新增测试使用内存角色，覆盖实际H输入、B独立菜单、暂停恢复、帮助关闭、扣蓝、冷却、切装保留冷却、敌我区分、学习装配、技能受击中断、死亡与重置清理。可见渲染已核对详情布局和三件法宝/两项技能的帧图；裁剪后的落剑、冰阵与火柱按脚点固定底边。截图在 `.godot/magic-checks`。

共享的技能动作、成长、命中与位移数据资源支持编辑器执行，以便 EquipmentDefinition 的法宝能力引用在 Inspector 中加载为正确类型；仅数据资源增加 Tool，不让战斗行为在编辑器运行。最终导入未报错。

整关 GameplayUpgradeSmokeTest 已通过真实局内法宝按钮/关闭、悟空技能、Boss攻击、波次和胜利返回地图检查，但最后“解锁水帘洞并获得指定装备”断言未通过，不能将整关回归标为全部通过。SkillCatalogSmokeTest 的功能断言全部通过，退出仍有音频资源占用警告；本批内存角色测试与 ContentSystemsSmokeTest 正常通过。日志分别为 `.godot/magic-gameplay-final.log`、`.godot/magic-skill-final.log`、`.godot/magic-new-final.log`、`.godot/magic-content-test.log`。
