# 无双系统

## 目标与范围

还原旧工程已接入角色与法宝的无双获取、满值保留、开启、消耗、伤害与移动加成、霸体和残影。技能的无双值属于技能资源，普攻和特殊阶段允许在命中配方覆写。时装等装备通过现有被动目录声明无双期间的 Buff；本次不虚构未迁入的时装、八戒减伤、专属剑阵或分身内容。

## 旧版依据

`BaseMonster.cureWSValue` 在伤害处理前增加攻击 `WSValue`，缺失时为 2；闪避仍获取，受伤、击杀、空挥均没有额外获取，无双期间禁止获取。每个目标、每个命中窗口分别结算。角色字典每物理帧重建随机整数；独立弹体复制字典。本工程按玩家、命中配方与源技能在每个物理帧缓存一个闭区间随机整数，同帧同攻击接触多个目标共用它；弹体发出时快照一次，不按施法次数奖励。

`BaseRoleProperies` 上限 100；`BaseThroughLevel.tscn/Timer` 每 0.5 秒运行：未满减 0.2、开启减 4。由于旧变量 `ws_value: int`，未满时减 0.2 赋回整数实际减 1，不能改为浮点缓慢衰减；满值不扣。开启不重置关卡时钟，因此持续最多约 12.5 秒。旧 `ws_up_power=1.5` 在旧伤害公式后乘算，同时加成水平移动；免击退与受击打断但仍掉血。空格开启，K 跳跃。

## 模块、数据与运行状态

- `WushuangGain` 资源保存最小/最大整数。`SkillDefinition.WushuangGain` 为默认获取；`HitDefinition.WushuangGain` 优先覆写（普攻、火魔斩落地），空引用回退 2。零值资源明确禁止获取；持续伤害脉冲使用零获取，不能误用普通接触的默认值。
- `WushuangRuntime` 归 Player，独占无双值、开启状态和 0.5 秒时钟。读取基本无双 Buff 资源，不修改共享资源；暂停随玩家物理帧冻结，死亡、重生、换关清零，不存档。
- `Content/Combat/Wushuang.tres` 声明基本 Buff：结算后伤害倍率 1.5、移动倍率 1.5、霸体。`BuffRuntime` 统一聚合这些属性；霸体仅免非致死攻击的打断与击退。
- `BuffGrantEffect.OnlyDuringWushuang` 是装备/固有被动的条件入口，`PassiveEffectRuntime.RefreshBuffSources` 在开启、结束与装备刷新时重建永久来源。时装可授予伤害、减伤、移动、治疗或范围攻击 Buff，沿用 ID 去重和来源移除规则，获取规则不受这些 Buff 修改。
- HUD 仅读取值和状态，复用 `ws_effect/max_ws`；残影组件采样当前角色精灵，0.1 秒生成一次，0.27 秒消失，沿用旧色彩与透明度，不复制脚本或碰撞。

## 调用链与注册扩展

接触/范围/弹体 → CombatResolver（有效敌方活目标检查后、闪避分支前）→ 玩家无双获取；弹体携带自身的获取快照与源技能。伤害公式 → Buff 结算后倍率 → ReceiveHit；ReceiveHit 通过 Buff 霸体避免打断。玩家物理帧推进无双计时与读空格 → 应用/移除基本 Buff → 刷新条件被动。装备技能按现有 EquipmentPassiveSkills 资源引用显式注册，无双运行时不读取角色/装备/技能 ID。

新增技能配置 `WushuangGain`；同技能特殊阶段在 HitDefinition 配置覆写。新增时装在装备 PassiveSkills 引用 PassiveSkillDefinition，其 BuffGrantEffect 配置 `OnlyDuringWushuang=true` 和对应 Buff。永久来源由系统管理，不应手动向无双值写入，也不应在 UI 授予 Buff。

## 失败处理与验证

无效区间拒绝使用；基本 Buff 缺失时拒绝开启；未满、死亡、禁行动或重复开启不消耗值。配置按现有 Buff/被动验证后应用。残影节点短时独立存活，不保留角色节点或战斗来源。

验证技能与普攻迁移数值、各阶段覆写、零值/默认值、多目标/多段、闪避获取、致死接触、持续伤害不获取、满值保留、整数衰减、时间补偿、暂停、开启中禁止获取、伤害倍率、霸体仍掉血且死亡、装备条件 Buff 穿脱与结束清理、HUD、弹体快照及死亡/重生清理。编译并回归现有技能/Buff测试。

## 当前实现与验证结果

上述基础无双已接入悟空、唐僧与三件现有法宝。`Tests/WushuangSmokeTest.tscn` 通过旧值资源检查、真实四段风暴、两目标弹体快照、零伤害接触不重复获取、条件装备 Buff、死亡/重生及 HUD 检查；原生渲染确认残影与无双条，带 `-- --capture-wushuang` 保存 `.godot/wushuang-checks/active.png`。编译零警告、零错误；BuffTrapMechanics、MagicAndTangseng、PassiveEffects、PlayerResources 回归断言通过。既有回归程序仍可能报告音频退出资源残留；专项测试已隔离无关声音，正常退出。

条件 Buff 扩展示例：在时装的 `PassiveSkillDefinition.Effect` 引用 `BuffGrantEffect`，设置 `OnlyDuringWushuang=true`，其 `Buff` 可配置 `DamageReduction=0.2`（无双期间减伤20%）或 `OutgoingDamageBonus=0.2`（在基础无双倍率外增加伤害）。穿脱仍调用现有装备刷新，不手动订阅无双事件。这个示例仅说明资源接法，不代表已有对应时装内容。
