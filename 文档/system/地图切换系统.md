# 地图切换系统

## 目标与范围

复用旧版人间、地府、天庭的布局、资源与动画，仅接入地图切换和已有公共菜单；新地图的关卡禁用，不创建关卡。开发阶段允许直接切换，预留击败牛魔王进入地府、击败转轮王进入天庭的判断。

## 职责与状态

`WorldMapDefinition` 保存场景、公共按钮路径、相邻地图引用、首领开启标识和提示。`Content/Maps` 显式配置三地图。`WorldMapAccess` 统一判断条件，资源的开发放行开关关闭后检查存档 `DefeatedBossIds`。尚无相应首领关卡，不伪造击败状态。

`WorldMap` 共用控制器准备会话、绑定配置按钮、复用学习/任务服务；已有三关仅在人间开放。切换按钮 → 重新检查条件 → 关闭菜单 → 保存 → 切换场景。返回前一地图不限制。当前地图属运行态，加载仍进人间。

## 扩展、失败与验证

未来首领结算登记资源指定标识并保存，再关闭资源的开发放行；控制器不判断具体首领 ID。缺少目标、条件不符、保存失败时保留当前地图并提示。存档拒绝空集合或空标识，无迁移逻辑。

验证旧资源存在、三地图往返、未实现关卡禁用、学习/任务菜单、开发放行关闭时条件拒绝及登记后允许。测试使用内存会话或独立用户目录。

`EarlyContentMigrationSmokeTest` 已通过无界面及实际渲染测试：人间→地府→天庭→地府→人间、天庭直接回人间、未满足条件拒绝、首领记录序列化。保存及新资源导入通过。截图位于 `.godot/migration-checks`；法宝截图位于 `.godot/content-checks/magic-detail.png`。地府和天庭尚无可进入的新关卡。
