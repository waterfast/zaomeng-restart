# 前三关战斗与出口接入记录

## 目标与设计

本轮接入花果山、水帘洞、桃花源的怪物波次、空气墙和落地光圈。花果山保留现有四波小怪加大猩猩；水帘洞和桃花源依据旧工程 Level_2.gd / Level_3.gd 的数组配置三波小怪加猕猴王 / 禺狨王。沿用 MonsterDefinition、SkillDefinition 与 WaveEncounter，不把关卡 ID 或怪物 ID 写入通用运行时。

出口坐标统一归 LevelDefinition，以地面脚点表达。GameplayLevel 在显示光圈前向下查询地面，LevelExit 用图像偏移对齐光圈底端，并以玩家脚点判断距离。查不到地面则报告配置错误，不生成悬空出口。波次资源拥有门禁位置、镜头右界、刷怪范围；最终空气墙与光圈相隔约 130–150 像素，清场后保持关闭。波次清场后释放中途门禁，最终门禁保留。

新增 Boss 场景包含碰撞、原版身体与随身特效帧图、动作库。原 GDScript 不接入；身体与随身光效由当前动作库同步驱动，命中窗口、弹体与地面技能由共享技能资源配置。定点范围技能复用 CharacterActor / SkillBehavior 接口，按敌对队伍选择目标，玩家也可使用同一资源。怪物模板负责属性、奖励、掉落和技能优先级；实例持有血量和冷却。难度沿用已有独立难度资源。

## 验证方案

编译；前三关普通模式真实移动输入、清波推进、最终墙物理阻挡、Boss模板与数量、光圈脚点、W结算逐关解锁；新技能对敌队造成伤害且不伤同队，施法者死亡后取消；现有花果山结算回归；实际渲染核对 Boss 和光圈。流程巡检通过战斗接口快速清场，不用它声称原版战斗平衡完成。

### 新 Boss 与共享技能

- 猕猴王：600生命，10级，基础攻击55，物防50、魔防80，50经验、20灵魂。普通棍击、通风呼啸风弹（8秒冷却）、范围震击（旧动作 jfkx）（11秒冷却）。
- 风弹起手第 0 帧补上随手势移动的蓝球，按旧场景在 0.7、1.4 秒各发射一次；手上光效与飞行弹体共用帧图，受击、死亡和池复用清除未释放的光效与后续发射。手上蓄力属于本轮补充表现，旧场景没有独立蓝球蓄力节点。
- 禺狨王：1200生命，13级，基础攻击55，物防50、魔防80，80经验、30灵魂。普通攻击、锁定敌人脚点的阴阳之力地面打击（15秒冷却，约1秒预警）。
- 数值和名称依据旧 Monster_4.gd / Monster_5.gd，风弹/范围技能将原伤害90/80/75表达为基础攻击55的倍率。速度映射到当前每秒像素制，检测范围适应当前地图；战斗平衡未做原版逐帧标定。
- 两只 Boss 的身体帧图和动作时序分别提取自旧 Monster_4.tscn / Monster_5.tscn；风弹帧图来自旧 Scene/Bullet/Fly_bullet.tscn 的 Monster4Bullet 动画，禺狨王地面特效来自旧 Scene/Monster/MonsterBullet.tscn 的 Monster5Bullet 动画。原 GDScript、旧碰撞开关、旧方法轨道没有接入。
- 猕猴王掉落以50%概率抽取 dszy / dslq / dshp / dslj 中一件；禺狨王以50%概率抽取 dsqz / dsyj / jmc / zhj 中一件。沿用怪物模板独立掉落表，困难模式额外表仍按现有规则单独结算。
- 风弹使用既有 SkillProjectile；猕猴王震击恢复旧特效的两阶段缩放和 1.5 倍动作节奏，按共享技能窗口命中 14 段。禺狨王范围攻击由 AreaAttackBehavior 锁定和预警、AreaAttackEffect 独立播放六段爆发，共用 CharacterActor / SkillDefinition / SkillBehavior，按敌对队伍结算。锁定后玩家能离开预警区；死亡、隐藏和池复用取消后续爆发，受击中断取消未释放部分。玩家复用测试使用同一个行为场景，仅绑定到双方已有的动作。
- 怪物追击距离改为技能列表中最短攻击距离；远程技能冷却时继续接近近战范围，避免站在最远范围里等待。

### 地图画面修正

水帘洞水面由跨岸大矩形拆为两段河槽，水位降低35像素；水纹独立平移、重复采样并裁剪，不再继承水底四倍横向缩放。桃花源旧地砖节点误迁为 Node2D，现已恢复 TileMap 并提高地面层级，草地正确盖住树根；初始迁移工具也修正节点类型识别。已有连续坡面保留，此轮没有重新生成地图或覆盖其他策划修改。

- 编译通过：0警告、0错误。
- HumanCampaignSmokeTest：十关连续移动与 W 解锁通过；新增前三关首波空气墙物理阻挡、清场数量、光圈脚点、最终墙保持、从墙边走回光圈的断言通过。全程无玩家传送，出怪加速20倍，通过 CombatResolver 快速清场；这是流程与地形验证，不是无作弊通关或战斗平衡验证。
- EarlyBossSkillsSmokeTest：新 Boss 所有技能可释放且实际造成伤害、锁定脚点可躲避、友军免伤、死亡取消、玩家复用同一范围行为通过。
