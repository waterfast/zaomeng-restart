# 灵魂幻境原创瓦片关卡

## 目标与范围

使用已有64×64草地试样搭建原创“幻境碎岛”，接入人间地图的 level_lhhj 传送门（旧标签为轮回幻境，按本轮命名为灵魂幻境）。新增岩石实体块、水体和动态水纹瓦片。所有可行走地形来自 TileMapLayer，每格碰撞由 TileSet 保存；水格无地面碰撞，路线走桥台。复用现有怪物模板和波次，不将此试作宣称为旧幻境副本还原。

## 模块与状态归属

Content/Terrain/RealmTileSet.tres 显式登记草地、岩石、水体、水纹四种来源；草地/岩石使用地形层1，水体/水纹只作画面。地图按 Ground、Water、WaterSurface 层摆放，主体不使用整体 CollisionPolygon2D。Scenes/Maps/Human/SoulRealm.tscn 保存地图与背景；Content/Levels/soul_realm.tres 保存出生点、镜头、出口、难度和波次；Scenes/Level/SoulRealm.tscn 复用 GameplayLevel。

现有 ProgressLevel 同时用于入口锁定与主线结算，因此新增 AdvancesCampaign（默认true）区分实际主线与副本。幻境入口要求进度1，可直接试玩；胜利只保存本局奖励，不解锁下一主线。通用运行时读取这一字段，不判断关卡ID。人间主线移动测试按该字段筛选，保留十关语义；幻境使用独立路线测试。

## 布局与扩展

出生平台 → 第一水池桥台 → 石台与悬空路线 → 第二水池 → 最终战斗平台/贴地出口。已配置三波现有怪物：四只小猴；三只大猩猩加一只小猴；猕猴王。最终空气墙仍由遭遇配置生成。地图长3584像素，左边界也由独立岩石格封住。新素材通过独立 AtlasTexture 指定旧场景引用图片的区域，地图可直接在编辑器涂格子，不依赖运行时生成脚本。

草地取227.png的(800,160,64,64)，岩石取同图的(1800,210,64,64)，水体取220.png的(0,0,64,64)，水纹取River.png的(0,0,256,64)，按四帧、每秒五帧播放。这些是旧美术的瓦片化试样，原创的是关卡布局；尚未制作无缝边角或坡面自动连接。Scenes/Maps/Preview/RealmTilePreview.tscn 展示放大的草地、岩石和组合水面，可单独运行查看。

## 失败与验证

关卡/模板沿用现有Validate；无地面出口拒绝显示。验证资源加载、水格不产生实体、岩石格可站立、原生渲染、悟空通过真实移动和跳跃到出口、波次清场和最终墙、点击地图幻境按钮打开试玩面板、通关不改变主线进度。水体目前无游泳/伤害规则；素材接缝和后续完整美术待调整。

## 本轮实际结果

编译0警告/0错误。HumanCampaignSmokeTest的 --realm-only 路径验证入口、实体格与水格碰撞、三波清场、空气墙、贴地出口、连续移动和跳跃、W结算与主线进度保持；测试通过战斗接口快速清场，不代表困难模式已完成实战平衡。人间十关连续移动回归及LevelConfigurationSmokeTest均通过且正常退出。原生渲染已核对关卡和瓦片试样，截图位于 .godot/soul-realm-view.png 与 .godot/realm-tile-preview.png。
