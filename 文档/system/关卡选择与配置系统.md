# 关卡选择与配置系统

## 目标与范围

地图入口可以对应多个关卡变体。选择面板最初复用同级 `zmbh-rebuild/Scene/OtherScene/LevelInfo.tscn` 的布局和对应美术；本次已对照原始旧工程 `造梦八荒-(4.1)/Scene/OtherScene/LevelInfo.tscn` 及其脚本核对资源用途。左侧切换变体，展示怪物、Boss、可能掉落、难度及出怪速度。旧工程这份版本已删除难度选择，重构重新提供独立的资源配置。关卡启动、地图画面、战斗内容和结算名称读取同一份关卡定义。当前花果山和魔化花果山提供完整战斗变体；人间另外九个主线关卡已接地图试玩，原版怪物与 Boss 未迁入。

## 数据与职责

关卡变体与难度分开：变体定义地图、Boss、波次和原始掉落；每关显式引用自己的 `LevelDifficultyDefinition` 列表。模式分别配置小怪/Boss的生命、攻击、防御倍率及等级覆盖（0表示沿用模板），推荐等级覆盖和额外掉落表。普通保留原始模板；困难试玩设为20级，小怪生命×5、攻击×5、防御×1.25，Boss生命×10、攻击×3、防御×1.5。花果山与魔化花果山引用独立困难资源，方便各自调整。数值为依据20级角色成长的第一轮试玩调校，不宣称已完成实战平衡。选择模式和出怪速度只进入 `GameSession`，重试沿用；`GameplayLevel` 在进入时取得本次模式，同一配置供对象池与奖励使用。对象池每次出生从模板计算，不累计乘算。

掉落预览复用背包物品图与 `LegacyItemTooltip`，展示品质、类型、属性、描述、装备技能和售价，不把静态掉落伪装成拥有的实例。横向列表支持滚动条、滚轮和按住拖动；拖动时关闭提示。关卡选项使用挑战按钮的黄色贴图，选中状态使用高亮而非灰色禁用。验证覆盖切换关卡/难度、挑战传参、对象池倍率及滚动和提示布局。

`LevelDefinition` 是显式注册的策划资源，包含 ID、展示信息、进度编号、关卡容器场景、地图场景、怪物展示、模板掉落的派生预览，以及可选的 `WaveEncounterDefinition`。`WorldMapDefinition` 的入口列表把地图按钮与可选关卡资源关联，面板只消费数据，不判断关卡 ID。出怪速度是一次挑战的运行选择，不写入资源或存档。

`WorldMap` 检查进度并打开面板；确认挑战时设置 `GameSession.SelectedLevel` 并进入关卡容器。`GameplayLevel` 在进入场景时读取选中定义，替换容器中的地图节点；单独创建怪物池和出怪控制器。带波次配置的关卡由 `WaveEncounter` 管出怪、清场、门禁与镜头边界；明确标记 MapOnly 的地图试玩关卡抵达出口区域才开放光圈。无限随机刷怪与固定4600通关线已删除。关卡总控仍处理玩家、HUD、奖励、结算和存档。地图场景负责地形与表现，波次控制器用清波事件解除门禁；今后非波次地图可接不同的遭遇控制器，不必让地形资源承担刷怪规则。

## 扩展与失败处理

主线与独立副本共用入口、挑战与战斗流程。`LevelDefinition.AdvancesCampaign`默认true，灵魂幻境的“幻境碎岛”设为false；`ProgressLevel`仍表示入口解锁要求，副本胜利只保存奖励，不调用主线推进。具体地形和接入记录见[灵魂幻境瓦片关卡](灵魂幻境瓦片关卡.md)。

增加变体需建立资源并挂在入口配置；关卡容器与地图都必须存在。变体共用原关卡进度编号，因此通关仍解锁下一地图入口，不新增存档格式。魔化花果山当前复用花果山地形和猩猩 Boss，引用独立的魔化妖猴/大猩猩模板，改用更密的组合、不同普通掉落及不同难度；没有单独的魔化美术和怪物资源，不在 UI 中假称已经具备。

进入前校验资源、地图和关卡场景，失败时留在选择面板并给出提示。奖励资源 ID 必须在物品目录中存在；显示“可能掉落”不保证每项在一次通关内获得。掉落从怪物模板独立配置，不再按关卡统一的小怪/Boss数组发放。

## 验证

最小验证：编译资源类型；加载人间地图并切换花果山两项，确认标题、怪物及掉落变化；挑战进入对应定义并确认地图和波次读取配置；失败重试保持变体。本轮已通过人间十关悟空连续物理移动与 W 出口解锁；该测试通过战斗接口清场以隔离地形，不是完整战斗平衡验证。

## 模式额外掉落与20级试玩

`LevelDefinition.GetDropTables` 合并怪物原有掉落表与当前模式对应的小怪/Boss额外表。额外表单独判定概率，失败不影响原始掉落，成功不替代原掉落。`GetPossibleDropIds` 从实际波次模板及同一组掉落表派生预览；切换模式立即更新掉落和建议等级，不为没有怪物的地图试玩显示虚构奖励。普通、困难可有不同额外表，且各关可分别引用资源。模板与模式额外表的每项物品必须已登记；概率和数量非法时拒绝进入；判定成功生成地面物品，玩家走近后领取；自动拾取开启时落地满3秒领取。背包按需扩容，正常游戏不设格子上限；数量溢出等失败保留地面物品并提示；离开关卡不自动补发未拾取物品。

掉落按旧版怪物脚本登记：花果山小怪掉普通装备，大猩猩 Boss 不掉装备；水帘洞猕猴王掉地煞灵戒，桃花源禺狨王掉地煞袈裟、地煞猿甲（当前仅迁悟空、唐僧和通用物品）。撤销早期试玩添加的家传装备、七星守护和三件法宝奖励，困难不额外提前发放后期装备。地煞葫芦、天煞古剑、紫金葫芦在旧版由炼丹炉合成，不能为了测试法宝技能放入早期 Boss 掉落表；当前合成尚未实现。魔化花果山小怪同样遵循对应旧怪物的普通装备表。经验与灵魂不变。

选择面板在物品目录解析后过滤 Consumable 类别（含即时恢复补给），仅隐藏其预览；实际击杀补给和拾取行为仍由原掉落表负责。

20级基础属性参考：悟空1030生命/84攻击/29双防，唐僧620生命/129攻击/29双防。困难小猴300生命/50攻击，妖猴450/100，大猩猩1000/150，Boss3000/195；等级均20。小怪双防按模板×1.25，Boss×1.5。防御、技能倍率及装备仍影响实战伤害，数值验证不等价于人工通关体验。

验证覆盖普通不变、20级等级与小怪/Boss独立倍率、池复用不累计、独立概率与数量、额外表未登记拒绝、切换模式预览更新，以及实际死亡发放原始和额外奖励。

本轮验证结果：编译0警告/0错误；LevelModesSmokeTest、LevelConfigurationSmokeTest、MonsterTemplatesSmokeTest通过且正常退出。GameplayUpgradeSmokeTest两次功能断言均通过，但进程退出时在godotsharp_array_destroy/Array.Finalize发生0xC0000005，退出异常尚未定位；不将其记录为完整回归通过。专项测试用真实战斗致死和遭遇死亡事件验证发奖，但使用高伤害自动清场，不代表玩家已经通过20级困难实战。退出异常日志保留于`.godot/gameplay-mode-regression-retry.log`。

## 关卡音乐
LevelDefinition.Music 显式引用默认 MusicTrack；GameplayLevel 在场景就绪后交给常驻 AudioManager。玩家的关卡选曲覆盖场景默认，跟随场景或未知曲目 ID 使用此引用。结算停止循环背景曲并播放一次胜负提示，回到地图恢复菜单主题。音频播放状态不属于关卡统计或角色存档，见[音频系统](音频系统.md)。
