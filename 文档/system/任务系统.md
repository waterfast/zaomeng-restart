# 任务系统

先迁移旧 `Scene/Task` 的列表、描述、奖励及领取按钮；旧版 UI 混合条件判断、PlayerData修改和保存，新版只复用视觉与信号。首批为成长礼包1：10级，原奖励幸运的喜鹊2、孟婆药剂1、强化石宝箱10、1级宝石袋3。未实现奖励物品的使用效果保持不可用，但可正常领取及持有。日常、击杀、收集及复杂任务未登记为可用。

`QuestDefinition`、`QuestReward`、`QuestCatalog` 为独立 GameData 资源，英文翻译键与显式注册。领取ID保存在 `GameSaveData.ClaimedQuestIds`，完成度由当前角色等级推导。`QuestService` 先在背包副本演算全部奖励，成功才一次提交背包与领取记录，奖励可按需扩容；未达标、重复领取或数量溢出不发部分奖励。

`QuestInteraction` 复用已有 `RequestChannel` 与 `VoidEventChannel`，UI选择和领取信号提交请求，`QuestInteraction` 独占处理并协调保存/刷新。保存失败保留内存成功状态、单独提示；重复/嵌套请求拒绝。地图Task入口使用MenuManager暂停与互斥；面板打开或收到变更时刷新，关闭不修改任务状态。未来玩法进度由玩法事件产生，不能由UI按钮伪造。

注册新等级任务只需资源目录；其他目标先增加独立规则。验证旧资源引用、未达标、背包扩容、奖励原子提交、重复领取、领取记录序列化、真实按钮信号和释放订阅。

当前已接入主地图 Task 入口、旧任务列表/说明/奖励 UI、成长礼包1的实时等级条件和完整奖励，以及序列化领取记录。日常、击杀/收集任务尚未迁入。当前领取使用现有 RequestChannel 和 VoidEventChannel 的地图内连接；菜单打开不创建另一份任务状态。
