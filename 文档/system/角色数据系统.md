# 角色档案

`Scripts/Character/Character.cs` 是每个角色的长期数据。一个存档可以在 `GameSaveData.Characters` 中保存多个角色；角色 ID 必须唯一。`GameSaveData.Wallet` 保存灵魂和点券，本地 2P 共用这一份余额。

角色档案保存等级、经验、基础属性、永久属性加成、装备实例、已学技能等级、五个技能快捷栏与物理按键及已解锁天赋 ID。装备的属性和技能的动画效果都由各自的资源定义提供，档案中不复制这些定义。`CharacterActor`、`Player` 和 `CharacterMotor` 继续负责场上的移动、攻击、受击和当前生命；角色档案不在战斗中逐帧修改。

属性字段依据旧工程 `Script/Base/BaseRoleProperies.gd`，对应关系如下：

| 旧字段 | 新字段 | 含义 |
| --- | --- | --- |
| SHp / SMp | MaxHealth / MaxMana | 生命和魔法上限 |
| power | Attack | 攻击 |
| Def / Mdef | PhysicalDefense / MagicDefense | 物防和魔防 |
| Crit / Miss | CriticalRating / DodgeRating | 暴击值和闪避值 |
| R_hp / R_mp | HealthRegeneration / ManaRegeneration | 回血和回魔 |
| vampirism / Lucky | LifeSteal / Luck | 吸血和幸运 |
| Toughness / Htarget / CritReduce | Toughness / Accuracy / CriticalResistance | 韧性、命中和暴击抵抗 |
| ar / sp | ArmorPenetration / MagicPenetration | 破甲和破魔 |

存档和规则始终使用上表的英文字段名，界面中文名称只用于显示。例如 `MaxHealth` 是角色的生命上限，背包第一页的“生命”一行显示“当前生命/生命上限”；`MaxMana` 同理。旧工程的 `SHp`、`SMp` 属于上限，旧工程的 `Hp`、`Mp` 属于当前值，不能互相替代。

背包属性名称集中在 `CharacterStatsPresenter` 的行定义中，中文原文由 `Content/Localization/ui.csv` 翻译。CSV 第一列是稳定的界面原文，`zh_CN` 和 `en` 列是对应语言；例如“生命”对应 *Health*，“物防”对应 *Physical Defense*。新增属性时，同时补齐字段、行定义和翻译表。不要把译文写进存档，也不要根据界面文字反查属性字段。

`BaseStats` 与 `PermanentBonuses` 分开存储。`CharacterProgression` 按旧 `BaseRoleProperies.gd` 的五名角色固定基础值和每级增量计算 `BaseStats`；进入场景时会同步当前角色的基础成长值。成长属性不查表，只有 1～19 级的升级经验使用旧表，20 级起使用旧公式。`CharacterStatCalculator` 汇总基础属性、永久加成、技能目录中已学被动和已穿戴装备，供玩家场景与面板共用；不把合成后的最终攻击力写回档案。旧工程的 `Hp`、`Mp` 是当前资源量，`exp` 是经验，`coin_num` 是货币，均未混进属性结构。已学被动通过 SkillCatalog 的逐级加成表参与汇总；临时 Buff 尚未实现。

旧背包界面会用 `Crit / (Crit + 100)`、`Miss / (Miss + 100)` 显示概率，所以暴击和闪避字段保存原始属性值，不保存换算后的百分比。`LifeSteal` 沿用旧工程的小数比例（例如 `0.1` 表示 10%）。
