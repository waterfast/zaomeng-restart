# 本次整合记录

本轮将花果山迁移、角色/技能注册、装备授予技能、属性与成长、任务及相关界面整合到同一 C# 工程。本文记录当前可用内容与验证边界；编辑方法见[内容注册与调用指南](内容注册与调用指南.md)，各系统设计见[索引](README.md)。

## 关卡与战斗表现

- 花果山使用旧地图，4波小怪（9/14/15/5）之后单独出现大猩猩Boss。怪物脚底与实际碰撞地面统一，冲刺/击退均走碰撞移动，坡道和墙体不再直接穿入。
- 各波空气墙与摄像机边界配套，清波才解除前面的墙。最后墙收在x=4000的平地，后方坡道及留白不可进入，第四波与Boss出生区同步缩到墙内。
- 前进提示与连击提示使用旧版动画；Boss血条绑定实际血量。主地图按钮恢复旧版悬停/按下反馈。
- 升级后按新的属性上限回满生命与魔法。经验、灵魂、装备掉落仍由现有奖励与存档链处理。
- 悟空/唐僧分别播放迁入的死亡效果，等待身体动画和独立墓碑特效结束才显示失败页。
- Boss清场后保留移动和拾取，待死亡表现后出现旧版通关光圈；靠近新按W才结算和解锁。光圈等待时继续回收尸体，不能提前进入胜利页或在范围外误触发。
- 胜利/失败页复用旧场景美术，支持重试、返回地图、战斗详情；胜利显示评价、用时、血蓝及最高连击。重试建立新一局，切场景释放暂停。本局伤害、治疗、闪避等统计不进存档。

设计：[关卡表现系统](关卡表现系统.md)、[战斗数据系统](战斗数据系统.md)、[玩家资源系统](玩家资源系统.md)。

## 角色、学习与技能

- 显式角色目录登记悟空和唐僧。悟空9个主动与4个被动，唐僧试玩包含冰龙波、天降甘露及3个通用被动；通用运行时不按角色/技能Id硬写执行分支。
- 学习、逐级费用、装配、改键、技能槽和保存使用统一服务；主动最高10级为本轮设定，通用被动保持6级。不同角色有独立学习记录。
- 成长费用/蓝耗放入独立SkillGrowth资源，伤害增量在命中资源中。装备等级加成参与生效等级，学习等级不被覆盖。
- 技能正文说明作用；图标右下问号读取当前等级蓝耗、倍率、冷却或被动加成，升级后刷新。特殊行为自行提供额外数值，不用正则解析描述。
- 基础冷却采用旧脚本数值直接作为秒数的新平衡设定，配合极速缩减；与旧版每帧扣0.1、60帧及快捷栏除6的实际计时区别明确。烈焰闪2.8秒、火魔斩4.8秒，技能独立冷却，不保留旧版封堵无缝连招的关联补丁；火魔斩落地后才启动自身冷却，中断也不能绕过。
- 快捷槽改为固定背景框＋独立Icon＋冷却遮罩＋快捷键，空槽和已学槽均有底框。缺失技能图标使用统一黑框。

设计：[技能系统](技能系统.md)、[技能成长系统](技能成长系统.md)、[动作位移系统](动作位移系统.md)。

## 属性、装备与背包

- 人物属性由资源目录注册，面板和装备说明共用名称、格式和悬停说明；新增极速与技能等级加成。极速缩短技能冷却，不改变动作速度，施放时固定本次时长快照。
- 增加武器、防具、饰品、法宝等目录资源，装备定义、装备实例、宝石及穿戴状态仍各有唯一归属。
- 装备可显式授予多个触发技能；如意金箍棒附大品天仙决，有效暴击命中恢复最大血蓝各20%。换装重建技能集合，同Id去重，卸下立即失效，装备授予技能不写学习记录。
- 装备技能名称、正文模板、图标及参数属于技能自身，装备只引用；背包预览与战斗消费同一来源。物品及装备技能说明接入中英文CSV翻译键。
- 已生成狂暴、永恒、辉煌、大品天仙决图标，并核对葫芦、铃铛原版物品图片。
- 白装批量出售已接入，保留已穿戴、有宝石和无售价的装备；法宝入口打开旧版详情面板，展示当前穿戴，穿戴继续走背包已有请求通道。

设计：[角色属性系统](角色属性系统.md)、[装备交互系统](装备交互系统.md)、[装备技能系统](装备技能系统.md)、[法宝界面系统](法宝界面系统.md)。

## 任务、状态与文档

- 主地图任务入口复用旧UI。当前注册10级成长礼包：幸运的喜鹊2、孟婆药剂1、强化石宝箱10、1级宝石袋3。
- 任务定义/奖励/目录显式注册；按钮发请求，QuestService按当前等级核验并试算完整奖励，一次提交背包和领取记录。格子不足时自动扩容，数量溢出不发部分奖励，重复领取拒绝，保存失败明确报告已发放状态。
- 领取记录属于整份存档，角色学习和装备实例属于角色。临时战斗效果、派生技能集合、冷却与结算快照不序列化。

- 新增注册与调用指南，提供新增等级礼包、武器、装备效果、主动/被动技能的步骤，解释服务连接、保存和订阅释放。

设计：[任务系统](任务系统.md)、[事件系统](事件系统.md)、[存档系统](存档系统.md)。

## 2026-10-05：早期装备、地图切换与法宝界面

- 依据旧 `AllEquipment.gd` 和 `LevelInfo.gd` 的实际配置补入35件早期装备，与已有10件合计45件武器、防具、饰品；包含如意金箍棒阶段及此前各角色对应装备。随机数值暂取中值，保留原归属、品质、售价和物品图引用。仅登记内容，不新增关卡掉落或自动修改玩家背包；八戒、沙僧、白龙的角色运行时仍未迁入。

- 地煞猿甲授予独立“地煞怒火”资源，烈焰风暴每段伤害提高50%，卸下立即失效。装备效果增加通用结算前 `ModifyOutgoingDamage` 时机，近战、弹体和延迟效果显式传递来源技能，避免用当前动画猜来源；烈焰风暴本身无需增加装备分支。
- 设计评估：常驻已学被动在属性重建时汇总，由暴击、回复、吸血、冷却运行端消费；暴击恢复使用有效命中后时机，技能增伤使用结算前时机。通用层不判断装备或技能 ID。同类增伤只需配置资源，新规则可独立编写效果子类；受击、死亡、持续Buff等时机仍待扩展，不宣称所有被动都已支持。
- 修复反复地图切换中属性说明目录的生命周期问题，由 `CharacterStatCatalog.Default` 保持共享目录引用。新法宝展示资源可在编辑器加载，资源导入无错误。
- 验证通过：零警告/零错误构建；`EarlyContentMigrationSmokeTest`、`ContentSystemsSmokeTest`、`EquipmentSkillsSmokeTest`、`SkillCatalogSmokeTest`、`EquipmentArchitectureSmokeTest`、`ItemActionsSmokeTest`、纯C# `SaveLogic`。新增测试覆盖四段真实命中、段内去重、其他来源不增伤、卸下失效、延迟来源、地图往返/条件拒绝及首领记录序列化；地图与法宝的实际渲染检查也通过。截图/测试日志留在忽略目录 `.godot`。
