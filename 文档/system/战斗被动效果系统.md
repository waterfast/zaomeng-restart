# 战斗被动效果系统

## 目标与范围

统一怪物固有被动与装备授予被动，不让角色、技能行为判断具体内容 ID。将现有指定技能增伤和暴击回复迁入统一接口，增加条件式攻击参数修改。通风大圣显式授予猕猴王：当前生命严格低于 20% 时，伤害 ×2、动作攻速 ×1.5、范围 ×1.5；数值在资源配置，回血至阈值以上解除。这是条件被动，不是永久锁定的 Boss 阶段。

## 职责与数据

- PassiveSkillDefinition：稳定 ID、翻译键、图标、效果资源、调用优先级。装备和 MonsterDefinition 均显式引用；不写学习记录。
- PassiveEffect：共享资源只保存配置，提供施法参数修改、伤害结算前修改、有效命中后回调。不同效果覆盖所需入口。
- PassiveEffectRuntime：每个 CharacterActor 独立拥有；合并固有和装备来源，相同 ID 同定义去重，同 ID 不同定义拒绝。按优先级、ID 固定顺序调用所有效果，不使用信号监听数量隐式决定结果。
- EquipmentPassiveSkills：只根据实际穿戴重建授予列表，战斗回调归公共运行集合。
- SkillParameterEffect / HealthRatioCondition / AttackParameterModifiers：目标技能资源筛选、普攻开关、可复用血量条件和参数配置。条件在调用时评估，无激活状态写入共享资源，无重复订阅。
- AttackParameters：一次普攻/技能的不可变运行快照；动作攻速、攻击范围、视觉大小、弹体速度/寿命、特效播放速度/寿命、动作移动速度。可显式替换技能通用特效场景和弹体场景，替换项按优先级后者覆盖。身体不放大，命中框与指定的特效缩放节点独立应用。

伤害沿用现有每次命中读取当前有效效果的语义，卸装与血量条件变化即时生效；其余攻击参数在起招前计算，已经发出的弹体保留释放时快照。基础技能引用始终保留用于学习、来源筛选和冷却；不修改公共资源。攻速改变动画时钟，行为、命中和方法轨道同步加快；不等同于极速或技能冷却。退出攻击、受击、死亡和池复用恢复动画速度、命中框与特效缩放。

## 调用链与扩展

模板/穿戴 → 校验并重建被动来源 → 普攻或技能起招 → 按序调用 ModifyAttackParameters → 校验快照 → 动画/命中框/行为/弹体/范围效果消费快照。有效命中 → ModifyOutgoingDamage → 防御/闪避/暴击 → ReceiveHit → OnHitDealt。两条链都接受 CharacterActor；魔法恢复仅在接收者拥有玩家魔法接口时执行。

同类强化仅新增条件和参数资源；不同规则新增 PassiveEffect 子类。不构建任意字段反射、通用表达式语言或全局事件总线。当前未实现永久阶段、持续 Buff、周期危险区、任意角色动作切换、自动替换角色内帧图，以及弹体数量修改；不能通过不存在的参数宣称支持这些能力。

## 失败处理与验证

拒绝无效血量阈值、非有限或非正倍率、无效替换场景、同 ID 不同定义；来源完整验证后整体替换。倍率组合为乘法；显式替换按配置优先级执行，相同优先级按 ID 保持确定顺序。导出的资源参数必须有实际消费端。

专项测试覆盖阈值边界、回血、玩家与怪物共用、目标筛选、来源去重及原子失败、真实伤害、多段、攻速时间、扩大近战判定、弹体/范围/特效参数、替换场景、公共资源不变、打断/死亡/池复用恢复。回归装备技能、迁入内容、Boss 巡检及原技能目录。本文件先记录设计，完成验证后记录实现结果。

## 实现与验证记录

已实现上述共用运行集合、条件式参数效果、通风大圣资源及猕猴王授予。原地煞怒火迁为目标技能筛选 + DamageMultiplier=1.5；原暴击回复迁到公共命中后接口。普攻、近战命中、弹体、范围爆发、火眼、火魔斩、飞行和独立法宝消费各自适用的参数；治疗只消费动作和视觉参数，伤害倍率不改变治疗量。角色内特效缩放通过显式锚点登记，猕猴王蓄力球抬高中心并从真实视觉中心释放，避免强化后穿地或出手跳位。

PassiveEffectsSmokeTest 验证真实碰撞扩大、伤害组合、速度时钟、回血、来源去重、原子失败、弹体替换与独立寿命、范围爆发、动作速度、特效替换优先级及池复用。装备技能、早期内容、怪物模板、角色技能目录和法宝回归已通过；原生窗口 Boss 巡检普通和低血量各 12 项通过。巡检支持界面切换及 --rage-boss，关键帧位于 .godot/boss-checks，低血量文件加 rage- 前缀。

装备或固有被动可用 BuffGrantEffect.OnlyDuringWushuang 声明仅无双期间授予的 Buff；开启、结束与装备重建同步 RefreshBuffSources，沿用来源去重与移除。该条件适用于未来时装，无双获取数值不被装备增益修改。
