# 编辑器存档管理工具

项目内置 Godot 编辑器插件 `addons/SaveEditor`，启用后在编辑器下方面板显示“存档管理”。面板分为“角色与货币”“背包”“完整 JSON”三个页签；操作结果和错误会显示在顶部按钮下方。插件只在编辑器运行。

## 常用操作

1. “已有存档”列出默认 `user://saves` 目录内 1～99 号的 JSON 和 DAT 存档，包含只有备份文件的槽位。JSON 存档会显示角色名与等级；游戏运行期间产生的新存档可点击“刷新”查看。选中一项后点击“读取”，也可以手动指定槽位和格式。
2. 空槽位可指定背包容量并点击“添加存档”；这一步只创建内存数据，点击“保存”才写入文件。新存档默认带有孙悟空的角色档案。同一槽位已有 JSON 或 DAT 时不能覆盖式添加，请先读取或选择空槽位。
3. “角色与货币”页可改共享货币、角色名字/等级/经验。可用角色 ID 新增一份角色档案。关卡、坐标、当前血量和朝向不存档，每次进关从关卡默认状态开始。
4. 选物品和数量后点击“增加”或“扣除”。增加会先填已有堆叠，再使用空槽；规则和游戏背包相同。选中槽位可直接清空。所有操作先修改内存，点击“保存”才落盘。
5. “完整 JSON”页可修改技能、装备、角色属性等未做表单的持久字段。编辑后先点“应用 JSON”，通过存档与物品目录校验后再保存。
6. “删除存档”会先弹出确认框。确认后会删除所选槽位的 JSON、DAT、`.bak` 备份和 `.tmp` 临时文件，并刷新列表；删除无法撤销。

加密存档需要与游戏相同的 32 字节密钥，以 64 位十六进制填入密钥框；也可以在启动 Godot 前设置 `ZAOMENG_SAVE_KEY` 环境变量。插件不会把密钥写进项目文件。当前 `GameSession` 读取的是开发 JSON 存档；加密 DAT 只用于验证存档格式，游戏流程尚未读取它。

游戏内选档页会显示每份 JSON 存档的角色名和等级。输入存档号后点击“删除存档”，确认后同样会清除该槽位的主文件和备份；空槽位仍可从选角流程开始新游戏。

保存前会检查磁盘文件是否已被其他程序修改，防止覆盖运行中游戏写出的新状态。已有有效存档会由原存档模块保留 `.bak` 备份。修改后的内容须重新读档或重启运行中的游戏才能反映到游戏状态。

旧版同为版本 1 的存档即使含有 `player.scenePath`、坐标、血量等字段，也可以读取；重新保存时这些关卡内字段会被丢弃。

修改 C# 插件代码后，如编辑器报 `Giving up on assembly reloading` 或仍显示旧界面，需要关闭并重新打开 Godot 编辑器。项目构建后可运行 `Godot --headless --path <项目目录> --script res://Tests/SaveEditorSmoke.gd`，检查面板初始化和读档；检查过程不会保存或更改任何存档文件。`Tests/SaveEditorCrudSmoke.gd` 会实际增删存档，只能在重定向到 `.godot/test-appdata/` 下的独立用户目录运行。
