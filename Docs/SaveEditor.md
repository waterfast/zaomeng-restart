# 编辑器存档管理工具

项目内置 Godot 编辑器插件 `addons/SaveEditor`，启用后在编辑器下方面板显示“存档管理”。插件只在编辑器运行，不添加游戏内 UI。

## 常用操作

1. 选择 1～99 号槽位和文件格式，点击“读取”。现有明文文件为 `user://saves/save_01.json`，加密文件为 `user://saves/save_01.dat`。如果还没有存档，可指定背包容量并点击“新建”；新建后仍需点击“保存”才会生成文件。
2. “常用修改”页可改共享货币、角色名字/等级/经验。可用角色 ID 新增一份角色档案。关卡、坐标、当前血量和朝向不存档，每次进关从关卡默认状态开始。
3. 选物品和数量后点击“增加”或“扣除”。增加会先填已有堆叠，再使用空槽；规则和游戏背包相同。选中槽位可直接清空。所有操作先修改内存，点击“保存”才落盘。
4. “完整 JSON”页可修改技能、装备、角色属性等未做表单的持久字段。编辑后先点“应用 JSON”，通过存档与物品目录校验后再保存。

加密存档需要与游戏相同的 32 字节密钥，以 64 位十六进制填入密钥框；也可以在启动 Godot 前设置 `ZAOMENG_SAVE_KEY` 环境变量。插件不会把密钥写进项目文件。若游戏尚未接入存档逻辑，此工具创建的文件可用于提前准备测试数据。

保存前会检查磁盘文件是否已被其他程序修改，防止覆盖运行中游戏写出的新状态。已有有效存档会由原存档模块保留 `.bak` 备份。修改后的内容须重新读档或重启运行中的游戏才能反映到游戏状态；当前 `TestArena` 尚未自动加载这些存档。

旧版同为版本 1 的存档即使含有 `player.scenePath`、坐标、血量等字段，也可以读取；重新保存时这些关卡内字段会被丢弃。
